## 关于动态宝

动态宝是面向资本市场的**企业动态信息智能分发平台**。我们从上市公司公开披露的信息出发，经 AI-FILTER 系统对信息的数量与质量进行智能判定，沉淀出可量化、可订阅、可分发的结构化数据资产。

| 维度 | 说明 |
| :--- | :--- |
| **覆盖范围** | A 股 + 港股全市场上市公司动态 |
| **内容分类** | BA 业务动态 · ESG 可持续发展 · ETF / LOF / REITs 基金 |
| **更新频率** | 每日 3000+ 条，06:00–24:00 持续推送 |
| **数据形态** | BA 指数、BA 指标排行、活跃率、分发热词、实时快讯 |
| **分发方式** | 标准 RSS 2.0 · 免费开放给第三方平台与媒体 |

> BA 指标是动态宝根据上市公司发布的业务信息数量和质量，经 AI-FILTER 系统智能判定后的指标——把"披露了什么"转化为"披露得怎么样"。
